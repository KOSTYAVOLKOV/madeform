# Madeform — Kitchen portfolio

A responsive static HTML, CSS and JavaScript site for Madeform, a kitchen and interiors craft business serving Birmingham and the West Midlands. The portfolio uses the supplied kitchen photographs and includes a keyboard-friendly full-screen gallery.

## Preview

Run a local static server in this folder and open its address in a browser. There is no build step or package dependency.

## Deploy to Vercel

Run `vercel` for a preview deployment. After linking the project, run `vercel --prod` to publish. In project settings, use the **Other** framework preset, leave the build command empty, and use `.` as the output directory.

The Vercel ignore file includes only the site and the seven photographs referenced by the page.

## Before launch

The contact email shown on the site is a placeholder and should be replaced with Madeform's real contact address before publishing.
